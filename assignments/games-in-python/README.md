
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Praticar a criação de um jogo simples em Python usando strings, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Construção do Jogo da Forca

#### Descrição
Crie um jogo em Python em que o jogador tenta adivinhar uma palavra oculta, letra por letra, antes de esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatória de uma lista predefinida
- Exibir a palavra oculta com traços ou underscores para as letras ainda não descobertas, como _ _ _ _ _
- Aceitar palpites de letras por meio da função `input()`
- Registrar letras já tentadas e evitar repetições
- Diminuir o número de tentativas quando a letra for errada
- Encerrar o jogo quando a palavra for adivinhada ou quando as tentativas acabarem
- Exibir mensagens finais de vitória ou derrota

### 🛠️ Melhorias de Interação

#### Descrição
Aprimore a experiência do usuário adicionando feedback claro e uma interface mais amigável durante o jogo.

#### Requisitos
O programa concluído deve:

- Mostrar o estado atual do jogo após cada tentativa
- Informar se a letra escolhida está presente na palavra ou não
- Exibir o número de tentativas restantes em cada rodada
- Mensagens claras ao final da partida
- Usar nomes de variáveis legíveis e manter o código organizado
